# Plinko Review Drop

A classroom review game inspired by Basketball Review Shootout. Ask a question aloud, let a student with a correct answer choose a numbered disc, then press Drop.

- Six reusable discs, animated peg board, WIN and LOSE halves.
- Each drop independently uses one unbiased cryptographic random bit: 50% win, 50% lose. Disc choice and previous results do not affect the odds. Short sequences need not have equal wins and losses.
- The random bouncing route is animated to the chosen outcome; this is not a physics simulation that could bias the odds.
- Sound toggle, full screen, counters, reduced-motion support, keyboard controls and responsive layout.
- No libraries, accounts, tracking or student data storage.

## GitHub Pages
